# Лабораторная работа 1

## Структура файлов данных

 **Ratings.csv** - исходные данные.

 **Ratings_count.txt**
  - первая строка: значение минимального идентификатора пользователя из файла ratings.csv и количество строк с этим идентификатором.
  - вторая строка: значение максимального идентификатора пользователя из файла ratings.csv и количество строк с этим идентификатором.

 **sqlite.txt**
  - первая строка: версия SQLite.
  - вторая строка: список доступных режимов выводов.
